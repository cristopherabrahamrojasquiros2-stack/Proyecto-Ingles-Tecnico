Stage 3 • Final Concluding Post

Reflecting on My Web & Mobile Development Journey

📅 Published: November 2024 👤 Author: Cristopher Rojas ⏱️ Reading Time: 2 min Stage 3
Rubric Requirement 1: Concluding Post (Learnings & Challenges) ✓ Exact Count: 125 words (Meets 100–150 limit)

Developing this educational blog throughout the second period has been an enriching journey. I strengthened my technical English vocabulary, mastered responsive web design, and explored the dynamic world of mobile application development.

During the process, I faced several technical hurdles. Ensuring complete mobile responsiveness across different screen sizes and embedding video elements seamlessly required iterative CSS adjustments and testing. Furthermore, synthesizing complex technical documentation into concise English summaries challenged my communication skills. I overcame these difficulties by studying documentation, using modern CSS flexbox and grid techniques, and applying peer feedback to enhance user experience.

Ultimately, my blog evolved from a simple static webpage into an interactive, multi-stage platform. This project taught me that successful web development combines robust coding, clear bilingual communication, and continuous learning.

Mobile-First Layouts

Evolving the site across Stages 1, 2, and 3 with persistent dark mode and client-side comment storage.
