About The Author & Mission

Hello, World! Welcome to My Dev Space

Who I Am

My name is Cristopher Rojas, a 10th-grade student at Colegio Técnico Profesional Santa Lucía specializing in Web and Mobile Application Development. As an aspiring software creator, I am passionate about how code transforms abstract ideas into interactive, intuitive mobile applications that solve everyday problems.

Throughout my technical high school training, I have explored the fundamentals of algorithms, responsive interface design, and modern programming standards. I believe that understanding both frontend architecture and cross-platform mechanics is essential for the next generation of software engineers.

Purpose of This Blog

This blog serves as my central learning portfolio for the English oriented to Web Development curriculum during the Second Period under the guidance of instructor Estefanny Sánchez Solano.

The primary objectives of this website are:

  • Technical English Proficiency: Communicating complex software engineering concepts, workflows, and analyses clearly in English.
  • Theme Exploration: Investigating cross-platform mobile frameworks—specifically contrasting Flutter and React Native—to discover optimal development practices.
  • Multimedia & Web Integration: Building a modern, mobile-responsive web platform that integrates curated video resources, code breakdowns, and interactive classmate feedback.

My Chosen Topic: Mobile Application Development

Smartphones are the primary computing device for billions of people worldwide. Choosing mobile development as my theme allows me to analyze how developers maintain unified codebases across Android and iOS without sacrificing native fluid animations or hardware performance.
