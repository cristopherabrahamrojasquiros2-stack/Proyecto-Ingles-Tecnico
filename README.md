## 🌐 How to Publish Online for Free to Submit on Microsoft TEAMS

The instructions state:  
> *"Share the blog link with your teacher through the TEAMS platform."*

You can publish this static website online in under 2 minutes using either of these free options:

### Option A: Netlify Drop (Easiest — No account or git required)
1. Go to [https://app.netlify.com/drop](https://app.netlify.com/drop) in your web browser.
2. Drag and drop the folder `c:\Users\satur\OneDrive\Documentos\Ingles P` onto the page.
3. Netlify will instantly provide a live URL (e.g., `https://devmobile-ctp.netlify.app`).
4. Copy that URL and submit it on Microsoft Teams!

### Option B: GitHub Pages
1. Create a free GitHub repository (e.g., `english-blog-ctp`).
2. Upload the files from this folder to the repository.
3. In your repository, go to **Settings** &rarr; **Pages**.
4. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
5. Your website will be live at `https://<your-username>.github.io/english-blog-ctp/`.
